# Weather Forecasting App

A React + Vite weather dashboard powered by the OpenWeatherMap API.

## Setup

1. Sign up at https://openweathermap.org/api and get an API key.
2. Open the file `.env.local` in the project root.
3. Replace `your_openweather_api_key_here` with your real key.
4. Restart the dev server with `npm run dev`.

The app will use live weather data when the key is configured correctly.
